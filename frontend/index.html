Recommended Commands per Device

Upload output from as many of these as possible. The more commands, the richer the topology.

Required (at least one)

  • show cdp neighbors detailDiscovers connected devices & interfaces
  • show lldp neighbors detailAlternative discovery protocol

Strongly Recommended

  • show running-configHostname, VLANs, port-channels, VPC, routing
  • show ip interface briefInterface IPs and admin/line status
  • show interface statusPort speed, duplex, VLAN, media type

Optional / Enrichment

  • show version / show inventoryModel, serial, software version
  • show interface descriptionFallback topology when CDP/LLDP disabled
  • show etherchannel summaryPort-channel member details
  • show vpc / show vpc briefVPC peer-link and member ports (NX-OS)

Tip: One text file per device works best. Include the device prompt (e.g. switch-01#) so the hostname is detected automatically. Multiple commands can be in a single file.
