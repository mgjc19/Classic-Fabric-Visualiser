    Recommended Commands per Device

    Optimised for Cisco Nexus 9K with support for IOS-XE, NX-OS, Arista, Juniper, and other vendors. Upload output from as many of these as possible — the more commands, the richer the topology and migration plan.

    Required (at least one)

    • show cdp neighbors detailDiscovers connected devices & interfaces
    • show lldp neighbors detailAlternative discovery protocol (Arista/Juniper default)

    Strongly Recommended

    • show running-configHostname, VLANs, port-channels, VPC, routing config
    • show ip interface briefInterface IPs and admin/line status
    • show interface statusPort speed, duplex, VLAN, media type
    • show vlan briefVLAN database — used for VXLAN VNI mapping
    • show version / show inventoryModel, serial, S/W version — hardware capability check

    BGP / Routing Topology

    • show ip bgp summaryBGP peer table, ASNs, state, prefixes
    • show bgp neighborsDetailed peering state, remote AS, uptime
    • show ip ospf neighborOSPF adjacencies, areas, DR/BDR state
    • show ip ospf / show ip ospf interfaceOSPF process, router-ID, interface costs

    Optional / Enrichment

    • show interface descriptionFallback topology when CDP/LLDP disabled
    • show port-channel summaryPort-channel members and protocol (NX-OS)
    • show vpc / show vpc briefVPC peer-link and member ports (NX-OS)
    • show ip routeRouting table context for underlay planning
    • show nve peersExisting VXLAN NVE peers (if partially migrated)

    Tip: One text file per device works best. Include the device prompt (e.g. N9K-SPINE-01#) so the hostname is detected automatically. Multiple commands can be in a single file. For Juniper, show configuration | display set works as running-config.
